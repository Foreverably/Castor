PRIVACY POLICY

1. What Data We Collect

User Data (MongoDB):
- Discord user ID
- Discord username
- Economy data (coin balance, search cooldowns, search statistics)

Server Configuration (MariaDB):
- Discord guild/server ID
- Configured channel IDs, role IDs, and other server settings
- Jokes stored in the jokes database (added by server administrators)

Message Content:
- Message content is read in real time solely to detect and execute prefix-based commands (c?). Message content is not stored, logged, or transmitted anywhere beyond the Discord API.

Interaction Data:
- Slash command inputs and button interactions are processed in real time for command execution. They are not stored beyond what is necessary for the immediate response.

2. How We Use Data
- User data is used to track economy balances and gameplay history.
- Server configuration data is used to determine where and how commands operate.
- Message content and interactions are used exclusively to process and respond to commands.

3. Data Sharing
We do not sell, share, or transmit your data to any third parties. Data is stored on private databases controlled by the bot operator.

4. Data Retention
User economy data is retained until you request deletion or the bot ceases operation. Server configuration data is retained as long as the bot remains in your server. You may request deletion of your data at any time.

5. Data Deletion Requests
To request deletion of your data, contact the bot operator through the support server or directly via Discord. We will process deletion requests within 30 days.

6. Third-Party Services
Castor uses the following third-party services:
- Discord API (data transmitted to and from Discord)
- MongoDB (database hosting)
- MariaDB (database hosting)
- Browserless (headless browser for image generation)

Each service has its own privacy policy governing how they handle data.
